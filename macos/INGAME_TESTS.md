# In-game tests (end checklist)

One line per feature that only fires in game. Each line says what to do and which log line proves it.
Run the game through `launch_phase6.sh` with `CODEWARE_MAC_DIAG=1` (the launcher's default). The launcher prints
`Logs (send these): /tmp/cp2077-phase6-<stamp>-*`; every line below is in the `-launch.log` file of that session.

The hook counters and the callback deliveries are logged once at t+50s and again every 30 s while any count changes:
`[diag] R18 counts@t+<n>s <hook>=<calls>@<first ms> ...` and `[selftest] R18 callbacks@t+<n>s <event>=<deliveries> ...`.
A hook that never ran is missing from the first line. "Crash-free" means no `[crash]` line.

Status: the R18 gate passed (two menu boots of build `r18h-023c5521`) and the R19 gate passed (menu boots of build `r19k-43d732a6`: `r19k`,
`r19l`, `r19m`). Lines marked "seen at the menu" were seen in those boots, so they only need to be seen again in game; the others have not
been seen yet. **ArchiveXL 1.26.1 (old Mac build):** it hooks `ResourcePath::Create` with the Windows signature and crashes at once when
that hook is allowed (r19h), so `launch_phase6.sh` parks `ArchiveXL.dylib` during a session and puts it back afterwards. The ported
ArchiveXL (Stage 3) removes that need. The R20 gate passed (builds `r20e`, `r20f`) and the R21 gate boots are `r21h` and the next clean boot of the same build (`r21g` was the clean boot of the build before the spawner rows and the lock protocol).
